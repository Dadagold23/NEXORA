# 1. PROJECT VISION

Build NEXORA as a **Universal Programming Language and Universal Development Platform**.

The objective is not to create another ordinary programming language.

The objective is to create a unified programming ecosystem where developers can use one primary language and development environment to create:

* Web applications
* REST APIs
* GraphQL APIs
* Mobile applications
* Desktop applications
* Cloud applications
* Enterprise applications
* Database-driven systems
* AI/ML applications
* Automation systems
* CLI applications
* Distributed systems
* Real-time applications
* Embedded applications
* Server applications
* Infrastructure/cloud applications

while also being able to interoperate with existing programming languages and frameworks.

The conceptual philosophy is:

> **English allows people from different linguistic backgrounds to communicate through an adopted common language. NEXORA should provide a common software-development language through which different programming-language ecosystems can interoperate.**

NEXORA must therefore become an **orchestration and interoperability layer**, not simply a language that copies Python, Rust, PHP, JavaScript, Java, C#, Go, etc.

Use `prompt.txt` as the production-phase acceptance criteria and this file for module boundaries and approval gates.
